Modul 3: Custom Tools (@tool)

Lab 3: Membuat Custom Tools dengan Dekorator @tool

Model AI membaca fungsi Python Anda melalui Docstring dan Type Hinting. Pelajari cara mengubah fungsi python biasa menjadi alat otonom untuk membaca jam sistem dan menyimpan data catatan ke file lokal.

Praktisi

3 Aturan Emas Membuat Custom Tool di Smolagents

Agar LLM Gemini dapat menyusun parameter pemanggilan JSON secara akurat tanpa error, fungsi Python Anda harus mematuhi aturan berikut:

1. Type Hints Wajib

Setiap argumen (contoh: content: str) dan return type (-> str) wajib didefinisikan secara eksplisit.

2. Docstrings Google Style

Jelaskan fungsi alat serta bagian Args: di dalam triple quotes agar LLM paham kapan harus memanggilnya.

3. Return Teks Deskriptif

Kembalikan pesan status yang jelas dalam bentuk string sebagai bahan observasi bagi langkah berikutnya.

lab3.py 
import os
import sys
import datetime
import requests
import logging

# Fix encoding untuk terminal Windows
sys.stdout.reconfigure(encoding='utf-8', errors='replace')

from dotenv import load_dotenv
from smolagents import ToolCallingAgent, OpenAIServerModel, tool

load_dotenv()

# Aktifkan logging agar proses agent terlihat di terminal
logging.basicConfig(level=logging.INFO)

# ============================================
# 1. INISIALISASI MODEL VIA GOOGLE AI STUDIO (GEMINI)
# ============================================
GOOGLE_API_KEY = os.getenv("GOOGLE_API_KEY")
if not GOOGLE_API_KEY:
    raise ValueError("Set GOOGLE_API_KEY di file .env sebelum menjalankan script ini.")

# --- Pre-flight check ---
print("🔍 Mengecek koneksi ke Google AI Studio (Gemini)...")
try:
    test_res = requests.post(
        "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions",
        headers={"Authorization": f"Bearer {GOOGLE_API_KEY}", "Content-Type": "application/json"},
        json={"model": "gemini-3.6-flash", "messages": [{"role": "user", "content": "Hi"}], "max_tokens": 10},
        timeout=15
    )
    if test_res.status_code == 200:
        print("✅ Koneksi Google AI Studio berhasil!")
    elif test_res.status_code == 403:
        print("❌ API Key TIDAK VALID! Dapatkan key baru di https://aistudio.google.com/apikey")
        exit(1)
    elif test_res.status_code == 429:
        print("⚠️ Rate limit! Tunggu 1-2 menit lalu coba lagi.")
        exit(1)
    else:
        print(f"⚠️ Status: {test_res.status_code} - {test_res.text}")
except Exception as e:
    print(f"❌ Error koneksi: {e}")
    exit(1)

# --- Inisialisasi model ---
model = OpenAIServerModel(
    model_id="gemini-3.6-flash",
    api_base="https://generativelanguage.googleapis.com/v1beta/openai/",
    api_key=GOOGLE_API_KEY
)

# ============================================
# 2. DEKORATOR UNTUK MEMBUAT CUSTOM TOOL
# ============================================
@tool
def get_current_time() -> str:
    """Mengembalikan tanggal dan waktu saat ini di Indonesia (WIB)."""
    now = datetime.datetime.now()
    return now.strftime("%Y-%m-%d %H:%M:%S WIB")

@tool
def save_note(content: str) -> str:
    """Menyimpan catatan ke dalam file notes.txt.

    Args:
        content: Teks catatan yang ingin disimpan.
    """
    with open("notes.txt", "a", encoding="utf-8") as f:
        f.write(f"{datetime.datetime.now()}: {content}\n")
    return "Catatan berhasil disimpan ke notes.txt"

# Tool bawaan + custom
tools = [get_current_time, save_note]

# ============================================
# 3. INISIALISASI AGENT DENGAN CUSTOM TOOLS
# ============================================
agent = ToolCallingAgent(
    tools=tools,
    model=model,
    max_steps=5
)

# ============================================
# 4. JALANKAN PROMPT (Kombinasi Tool: Waktu + Catatan)
# ============================================
prompt = """
Sekarang jam berapa? Catat ke dalam file notes.txt bahwa saya sedang mengikuti workshop Agentic AI di hari ini.
"""

print("\n🚀 Menjalankan agent (Custom Tools: Waktu + Catatan)...")
try:
    result = agent.run(prompt)
    print("\n=== JAWABAN AGENT ===")
    print(result)
except Exception as e:
    print(f"\n❌ Agent error: {e}")

# Cek isi notes.txt
print("\n--- ISI NOTES.TXT ---")
try:
    with open("notes.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("File belum ada.")

Cara Menjalankan Lab 3

  1. Simpan kode di atas dengan nama lab3.py.
  2. Jalankan perintah berikut di terminal:
python lab3.py
File notes.txt akan dibuat secara otomatis di folder aktif Anda!
