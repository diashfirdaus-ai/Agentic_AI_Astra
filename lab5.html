Lab 5: Hermes Desktop Agent (Computer Use & GUI Gemini)

Bagi yang menginginkan pengalaman Full GUI / Desktop Native tanpa menyentuh PowerShell, CMD, WSL, atau terminal sama sekali. Menjalankan Hermes Desktop di Windows 10/11 dengan otak Google Gemini dan kemampuan Computer Use.

No-Code / Pure Desktop

100% Full GUI Experience — Tanpa Terminal & Tanpa Menulis Script .env

Hermes menyediakan aplikasi desktop native untuk Windows 10/11. Yang terpenting: API Google Gemini didukung secara native dan dapat dikonfigurasi langsung dari jendela menu Settings Hermes Desktop. Anda tidak perlu mengetik perintah terminal, tidak perlu menginstal Python runtime manual, dan tidak perlu membuat file konfigurasi teks.

1

Download & Instalasi Hermes Desktop

Installer resmi biner native Windows 10/11

Buka Halaman Download Resmi
Unduh File .exe

Buka tautan resmi hermes-agent.nousresearch.com/desktop. Di bagian Windows, pilih Download desktop app.

Double-Click Install

Setelah file installer .exe selesai diunduh: cukup klik ganda (Double click) → Ikuti wizard → Klik Finish.

Zero Command Line

Tidak perlu membuka PowerShell, CMD, atau WSL sama sekali. Semua binary runtime sudah terbungkus rapi di dalam aplikasi.

3 & 4

Input API Key & Pemilihan Model Gemini via GUI

Tanpa file .env dan tanpa command line

  1. Dapatkan API Key gratis di portal: aistudio.google.com/apikey
  2. Salin kunci Anda (berupa string seperti AIzaSy...).
  3. Di jendela Hermes Desktop, buka menu:
    Settings → Providers → Google AI Studio
  4. Tempel (Paste) API Key pada kolom isian, lalu klik tombol biru [ Save ].
  5. Selanjutnya buka menu:
    Settings → Model
  6. Pilih model Gemini Flash (misalnya gemini-2.5-flash atau gemini-3.6-flash).
Tips Kuota & Kecepatan: Sangat disarankan memilih Gemini Flash untuk tahap awal, karena agent melakukan banyak pemanggilan model secara berantai (multi-call) saat membaca file atau berinteraksi dengan browser.

5 & 6

Uji Koneksi Chat & Aktivasi Tools / Toolsets

Memastikan komunikasi LLM lancar lalu mengaktifkan kemampuan otonom

1. Uji Coba Chat Pertama

Jangan langsung mengaktifkan banyak alat. Masuk ke halaman Chat Hermes dan ketikkan salam perkenalan:

Prompt Pengujian:
Halo Hermes. Perkenalkan dirimu dan jelaskan model Gemini yang sedang kamu gunakan.

Jika Hermes menjawab dengan perkenalan dan menyebut Gemini, koneksi ke Google AI Studio telah 100% berhasil!

2. Mengaktifkan Toolsets di Settings

Buka menu Settings → Tools / Toolsets. Hermes Desktop menyediakan berbagai modul alat yang siap dicentang:

File Operations (Baca, tulis, edit berkas lokal)
Browser (Live search & web browsing)
Computer Use (Kendali UI Windows desktop)
Code / Terminal Execution (Opsional lanjutan)
MCP Server Integration (Model Context Protocol)

Saran Praktis: Awali dengan 3 alat pertama (File, Browser, Computer Use) agar kontrol eksekusi agent tetap fokus dan stabil.

Fitur Bintang: Computer Use pada Windows UI

Mengoperasikan komputer layaknya asisten manusia di depan monitor

Fitur Computer Use pada Hermes Desktop menggunakan modul Windows UI Automation native. Agent dapat melakukan tindakan visual secara langsung pada sistem operasi Anda:

Klik Kiri / Kanan
Mengetik Teks
Scrolling Layar
Membaca Interface

3 Skenario Praktik Nyata untuk Pengajar, Peneliti & Developer

Skenario 1

Otomasi Codebase & Pembuatan README

Misalnya Anda memiliki folder proyek lokal seperti D:\Project\CPE\. Minta Hermes menganalisis seluruh file secara mandiri:

Buka folder project CPE saya di D:\Project\CPE\. Analisis struktur project tersebut. Jelaskan setiap file Python yang ada. Cari bagian yang menggunakan TensorFlow. Kemudian buatkan file README.md yang lengkap. Jangan mengubah source code yang ada.
Skenario 2

AI Coding & Security Agent

Hermes dapat difungsikan sebagai partner inspeksi kode cerdas untuk berbagai domain AI spesifik:

🐍 Python Debugging: "Analisis error program ini dan perbaiki bug logic-nya."
🧠 TensorFlow CNN: "Analisis arsitektur model CNN ini dan cari penyebab validation accuracy rendah."
📷 OpenCV Focus: "Periksa program camera focus ini dan optimalkan algoritma deteksi blur."
🛡️ LLM Security Audit: "Audit project ini dari perspektif prompt injection, data leakage & model security."
Arsitektur: File + Browser + Computer
