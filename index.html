Membangun Aplikasi
Agentic AI Modern

Pelajari langkah demi langkah dari konsep dasar ReAct (Reason + Act), Web Grounding, pembuatan Custom Tools, hingga otomatisasi desktop Microsoft Word lewat Full-Stack Web Application.

Python 3.10+ smolagents (HuggingFace) Gemini 3.6 Flash (AI Studio) Flask + REST API PyAutoGUI & Pyperclip
Panduan Setup & Instalasi Langsung ke Lab 1
Persiapan

Setup Python & Environment

Panduan instalasi Python multi-OS (Windows, Mac, Linux), isolasi Virtual Environment (venv), instalasi dependensi, dan konfigurasi API key Google AI Studio (.env).

Buka Panduan Setup
Modul 1

Fondasi Agentic AI

Memahami perbedaan LLM Tradisional vs Siklus ReAct (Reason + Act). Menghubungkan smolagents ke Google Gemini 3.6 Flash via OpenAI Server adapter dan tes koneksi.

Mulai Lab 1
Modul 2

Agentic Web Search

Pencarian internet live menggunakan DuckDuckGoSearchTool untuk mengatasi batas waktu pengetahuan model LLM, digabungkan dengan penalaran kalkulasi dinamis.

Mulai Lab 2
Modul 3

Custom Tools (@tool)

Ubah fungsi Python native menjadi alat otonom bagi LLM menggunakan dekorator @tool, type hint ketat, docstrings Google-style, dan manajemen file I/O lokal.

Mulai Lab 3
Modul 4 (Puncak)

Full-Stack & Word Bot

Memadukan Backend Flask REST API, Light Web UI modern, dan otomatisasi Robotic Process Automation (RPA) pengetikan ke Microsoft Word desktop via PyAutoGUI & Pyperclip.

Mulai Lab 4
Solusi Error

Solusi & Troubleshooting
