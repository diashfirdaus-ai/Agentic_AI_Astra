Sebelum memulai lab, pastikan laptop Anda sudah memiliki Python 3.10 atau versi di atasnya. Siapkan virtual environment terisolasi agar dependensi tidak saling konflik.

Perintah Terminal / PowerShell

Jalankan di terminal Windows (PowerShell) atau bash:

# 1. Buat direktori proyek & virtual environment
mkdir agentai_workshop
cd agentai_workshop
python -m venv agentai_venv

# 2. Aktifkan venv (PowerShell di Windows)
.\agentai_venv\Scripts\Activate.ps1
# Atau jika di Mac / Linux: source agentai_venv/bin/activate

# 3. Upgrade pip & install dependencies
pip install --upgrade pip
pip install smolagents flask flask-cors pyautogui pyperclip requests python-dotenv duckduckgo-search

2 Lab 1
Pemula

Fondasi Agentic AI & Inisialisasi Model LLM

Pahami perbedaan antara Prompting biasa dan siklus Reasoning & Action (ReAct). Kita menghubungkan library smolagents ke endpoint Google Gemini 3.6 Flash melalui format standar OpenAI.

LLM Tradisional (Single-Shot Prompting)

Pengguna memberikan teks, LLM langsung menggenerasi jawaban dari bobot memorinya (cut-off data). Tidak dapat memeriksa fakta internet terbaru, tidak bisa memverifikasi hasil kalkulasi angka rumit, dan tidak bisa berinteraksi dengan sistem komputer.

Agentic AI (ReAct Pattern)

Agent memiliki siklus kerja: Think / Plan (menentukan langkah) → Action (memanggil tool, API, database) → Observation (mengevaluasi output alat) → Final Answer setelah semua langkah terpenuhi.

lab1.py 
import os
import sys
import requests
import logging

# Fix encoding untuk terminal Windows
sys.stdout.reconfigure(encoding='utf-8', errors='replace')

from dotenv import load_dotenv
from smolagents import ToolCallingAgent, OpenAIServerModel

load_dotenv()

# Aktifkan logging agar proses agent terlihat di terminal
logging.basicConfig(level=logging.INFO)

# ============================================
# 1. INISIALISASI MODEL VIA GOOGLE AI STUDIO (GEMINI)
# ============================================
# Dapatkan API Key di: https://aistudio.google.com/apikey
GOOGLE_API_KEY = os.getenv("GOOGLE_API_KEY")
if not GOOGLE_API_KEY:
    raise ValueError("Set GOOGLE_API_KEY di file .env sebelum menjalankan script ini.")

# --- Pre-flight check: Tes koneksi ke Google AI Studio API ---
print("🔍 Mengecek koneksi ke Google AI Studio (Gemini)...")
try:
    test_res = requests.post(
        "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions",
        headers={"Authorization": f"Bearer {GOOGLE_API_KEY}", "Content-Type": "application/json"},
        json={"model": "gemini-3.6-flash", "messages": [{"role": "user", "content": "Hi"}], "max_tokens": 10},
        timeout=15
    )
    if test_res.status_code == 200:
        print("✅ Koneksi Google AI Studio berhasil!")
    elif test_res.status_code == 400:
        body = test_res.json()
        print(f"❌ Bad Request: {body.get('error', {}).get('message', test_res.text)}")
        exit(1)
    elif test_res.status_code == 403:
        print("❌ API Key TIDAK VALID atau belum diaktifkan!")
        print("   Dapatkan key baru di https://aistudio.google.com/apikey")
        print(f"   Response: {test_res.text}")
        exit(1)
    elif test_res.status_code == 429:
        print("⚠️ Rate limit! Terlalu banyak request. Tunggu 1-2 menit lalu coba lagi.")
        print(f"   Response: {test_res.text}")
        exit(1)
    else:
        print(f"⚠️ Status tidak terduga: {test_res.status_code}")
        print(f"   Response: {test_res.text}")
except requests.exceptions.Timeout:
    print("❌ Koneksi timeout! Periksa koneksi internet Anda.")
    exit(1)
except Exception as e:
    print(f"❌ Error koneksi: {e}")
    exit(1)

# --- Inisialisasi model ---
model = OpenAIServerModel(
    model_id="gemini-3.6-flash",  # Gemini 3.6 Flash (gratis, cepat)
    api_base="https://generativelanguage.googleapis.com/v1beta/openai/",
    api_key=GOOGLE_API_KEY
)

# ============================================
# 2. INISIALISASI AGENT
# ============================================
agent = ToolCallingAgent(
    tools=[],
    model=model,
    max_steps=4
)

# ============================================
# 3. JALANKAN PROMPT MATEMATIKA SEDERHANA
# ============================================
print("\n🚀 Menjalankan agent...")
try:
    result = agent.run("Jika saya punya 25 apel, membeli 30 lagi, lalu memberikan 12 ke teman, berapa sisa apel saya?")
    print("\n=== HASIL AKHIR ===")
    print(result)
except Exception as e:
    print(f"\n❌ Agent error: {e}")

4 Lab 3
Custom Functions

Membuat Custom Tools dengan Dekorator @tool

LLM membaca fungsi Python berdasarkan Docstring dan Type Hinting. Pelajari cara mengubah fungsi python native menjadi tools otonom yang bisa dipanggil agent untuk membaca jam sistem dan menyimpan data ke file lokal.

Aturan Wajib Pembuatan `@tool`

Setiap argumen harus memiliki type hint (seperti content: str), tipe return (misal -> str), dan deskripsi lengkap di docstring """Args: ...""" agar LLM dapat menyusun parameter JSON dengan presisi.

GOOGLE_API_KEY = os.getenv("GOOGLE_API_KEY")
if not GOOGLE_API_KEY:

app = Flask(__name__)
CORS(app)

# ============================================
# HELPER: OTOMATIS BUKA / FOKUS MS WORD
# ============================================
def open_or_focus_word():
    """Membuka aplikasi Microsoft Word jika belum terbuka, atau memfokuskan jendela Word yang ada."""
    ps_script = """
    $proc = Get-Process winword -ErrorAction SilentlyContinue
    if ($proc) {
        $wshell = New-Object -ComObject WScript.Shell
        $wshell.AppActivate($proc[0].Id)
    } else {
        Start-Process winword
    }
    """
    try:
        subprocess.run(["powershell", "-NoProfile", "-Command", ps_script], check=False)
        time.sleep(1.5)
        return True
    except Exception as e:
        print(f"⚠️ Gagal fokus ke Word: {e}")
        return False

# ============================================
# 2. TOOLS DASAR (Kalkulator, Search, Catatan)
# ============================================
@tool
def get_current_time() -> str:
    """Mengembalikan tanggal dan waktu saat ini di Indonesia (WIB)."""
    now = datetime.datetime.now()
    return now.strftime("%Y-%m-%d %H:%M:%S WIB")

@tool
def save_note(content: str) -> str:
    """Menyimpan catatan ke dalam file notes.txt.

    Args:
        content: Teks catatan yang ingin disimpan.
    """
    with open("notes.txt", "a", encoding="utf-8") as f:
        f.write(f"{datetime.datetime.now()}: {content}\n")
    return "✅ Catatan berhasil disimpan ke notes.txt"

@tool
def save_summary(text: str) -> str:
    """Menyimpan teks ringkasan ke dalam file ringkasan_ai.txt (overwrite).

    Args:
        text: Teks ringkasan yang akan disimpan.
    """
    with open("ringkasan_ai.txt", "w", encoding="utf-8") as f:
        f.write(text)
    return "✅ Ringkasan berhasil disimpan!"

# ============================================
# 3. TOOL BINTANG: NGETIK DI MICROSOFT WORD
# ============================================
@tool
def type_to_word(text: str, wait_seconds: int = 2) -> str:
    """Mengetikkan teks ke jendela Microsoft Word yang sedang aktif.
    Secara otomatis akan membuka atau memfokuskan jendela MS Word terlebih dahulu.

    Args:
        text: Teks yang akan diketik ke jendela Word.
        wait_seconds: Waktu jeda sebelum mengetik agar jendela Word fokus (default 2 detik).
    """
    try:
        # Otomatis buka atau fokuskan jendela MS Word
        open_or_focus_word()

        # Hitung mundur sebentar
        for i in range(wait_seconds, 0, -1):
            print(f"Jendela MS Word aktif! Bersiap mengetik dalam {i} detik...")
            time.sleep(1)
        
        # Gunakan clipboard + Ctrl+V agar support Unicode/karakter Indonesia
        import pyperclip
        pyperclip.copy(text)
        pyautogui.hotkey('ctrl', 'v')
        time.sleep(0.5)
        
        return f"Selesai! {len(text)} karakter berhasil diketik ke Microsoft Word."
    except Exception as e:
        return f"Gagal mengetik: {str(e)}. (Pastikan izin aksesibilitas diaktifkan)"

@app.route('/chat', methods=['POST'])
def chat():
    data = request.get_json() or {}
    prompt = data.get('prompt', '')
    tool_mode = data.get('tool_mode', 'full')

    if not prompt:
        return jsonify({"status": "error", "answer": "Prompt tidak boleh kosong!"}), 400

    log_buffer = io.StringIO()
    final_answer = ""
    error_msg = None

    # === MODE KHUSUS MICROSOFT WORD ===
    if tool_mode == "word":
        mode_name = "📄 Microsoft Word (Auto-Typing)"
        try:
            from openai import OpenAI
            client = OpenAI(
                api_key=GOOGLE_API_KEY,
                base_url="https://generativelanguage.googleapis.com/v1beta/openai/"
            )
            log_buffer.write(f"[WORD MODE] Generating text from prompt...\n")
            
            completion = client.chat.completions.create(
                model="gemini-3.6-flash",
                messages=[
                    {"role": "system", "content": "Kamu adalah asisten penulis. Tulis teks yang diminta user secara langsung tanpa penjelasan tambahan. Tulis dalam bahasa yang sama dengan prompt user."},
                    {"role": "user", "content": prompt}
                ],
                max_tokens=2000
            )
            generated_text = completion.choices[0].message.content.strip()
            log_buffer.write(f"[WORD MODE] Generated {len(generated_text)} chars\n")
            
            # Langsung ketik ke Word
            result = type_to_word(generated_text)
            final_answer = f"{result}\n\nTeks yang diketik:\n{generated_text}"
            log_buffer.write(f"[WORD MODE] {result}\n")
            
        except Exception as e:
            error_msg = str(e)
            final_answer = f"Terjadi error: {error_msg}"
            log_buffer.write(f"[WORD MODE ERROR] {error_msg}\n")
    else:
        # === MODE LAIN (math, search, custom, full) ===
        if tool_mode == "math":
            tools = []
            mode_name = "🔢 Kalkulator Cerdas"
        elif tool_mode == "search":
            tools = [DuckDuckGoSearchTool()]
            mode_name = "🌐 Pencarian Internet"
        elif tool_mode == "custom":
            tools = [get_current_time, save_note]
            mode_name = "📝 Custom Tools (Catatan)"
        else:  # full
            tools = [DuckDuckGoSearchTool(), save_summary]
            mode_name = "🚀 Full Research Agent"

        agent = ToolCallingAgent(
            tools=tools,
            model=model,
            max_steps=6
        )

        # Retry logic untuk empty response
        max_retries = 3
        for attempt in range(1, max_retries + 1):
            try:
                with contextlib.redirect_stdout(log_buffer):
                    final_answer = agent.run(prompt)
                break
            except Exception as e:
                err_str = str(e)
                if "cannot both be empty" in err_str and attempt < max_retries:
                    log_buffer.write(f"\n[RETRY {attempt}/{max_retries}] Model returned empty, retrying...\n")
                    continue
                error_msg = err_str
                final_answer = f"Terjadi error: {error_msg}"

    return jsonify({
        "status": "success" if not error_msg else "error",
        "answer": str(final_answer),
        "log": log_buffer.getvalue(),
        "mode": mode_name
    })

if __name__ == "__main__":
    print("🚀 Server berjalan di http://localhost:8000")
    print("📄 Siapkan Microsoft Word dan posisikan kursor jika menggunakan mode Word!")
    app.run(debug=True, host='0.0.0.0', port=8000)

                            Penyebab: Kursor tersentuh ke sudut layar (0,0) saat
                            simulasi pengetikan berjalan cepat di Word.
                        

                    

                    

                        import pyautogui
pyautogui.FAILSAFE = False
