Panduan Troubleshooting & Solusi Error Runtime

Saat menghubungkan AI Agent ke OS desktop, port web server, dan API eksternal, seringkali terjadi hambatan teknis. Berikut adalah akar penyebab dan solusi kode teruji untuk mengatasinya.

1. PyAutoGUI Fail-Safe Triggered

Penyebab: Fitur keselamatan PyAutoGUI akan langsung menghentikan program jika kursor mouse tanpa sengaja tersentuh ke sudut layar (0,0) saat simulasi pengetikan berlangsung di Microsoft Word.

Solusi Kode:
import pyautogui
pyautogui.FAILSAFE = False

2. Karakter Indonesia Hilang di Word

Penyebab: Fungsi pyautogui.write() menyimulasikan tombol keyboard fisik tata letak US-ASCII. Akibatnya tanda baca khusus, aksara, atau emoji akan terpotong atau hilang.

Solusi Kode (Unicode Safe):
import pyperclip, pyautogui
pyperclip.copy(text)
pyautogui.hotkey('ctrl', 'v')

4. PowerShell ExecutionPolicy Block

Penyebab: Windows membatasi script eksekusi Activate.ps1 secara default dengan pesan "cannot be loaded because running scripts is disabled".

Solusi Terminal:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

5. Port 8000 Address Already in Use

Penyebab: Server Flask sebelumnya belum di-stop (masih aktif di latar belakang) atau port 8000 sedang dipakai aplikasi lain.

Solusi:
# Ganti port di lab4.py baris akhir:
app.run(port=8001, debug=True)
