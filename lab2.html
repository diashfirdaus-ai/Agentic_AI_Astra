Lab 2: Agentic Search (Web Browsing & Grounding)

Membekali agent dengan kemampuan berselancar ke internet untuk mencari data real-time, membaca snippet web, dan mengombinasikannya dengan penalaran logika multi-langkah (misal: mencari harga emas 24K hari ini dan menghitung pembelian 10 gram).

Menengah

Mengapa Web Grounding Sangat Penting?

LLM tanpa tool hanya mengetahui informasi sampai batas tanggal pelatihan (training cut-off). Melalui Web Grounding dengan DuckDuckGoSearchTool(), agent bertindak secara mandiri mencari sumber kredibel di web publik, mengekstrak fakta yang relevan, dan menggunakan fakta tersebut sebagai pijakan penalaran berikutnya.

1

Pencarian Web Otonom

Agent menyusun kueri pencarian sendiri sesuai instruksi dan mengeksekusinya via DuckDuckGo.

2

Membaca Observasi

Hasil web dievaluasi. Agent menyaring harga nominal per gram dari berita terpercaya.

3

Kalkulasi Multi-Step

Hasil harga dikalikan 10 gram secara matematis, lalu dirumuskan menjadi jawaban final untuk pengguna.

lab2.py 
import os
import sys
import requests
import logging

# Fix encoding untuk terminal Windows
sys.stdout.reconfigure(encoding='utf-8', errors='replace')

from dotenv import load_dotenv
from smolagents import ToolCallingAgent, OpenAIServerModel, DuckDuckGoSearchTool

load_dotenv()

# Aktifkan logging agar proses agent terlihat di terminal
logging.basicConfig(level=logging.INFO)

# ============================================
# 1. INISIALISASI MODEL VIA GOOGLE AI STUDIO (GEMINI)
# ============================================
GOOGLE_API_KEY = os.getenv("GOOGLE_API_KEY")
if not GOOGLE_API_KEY:
    raise ValueError("Set GOOGLE_API_KEY di file .env sebelum menjalankan script ini.")

# --- Pre-flight check: Tes koneksi ke Google AI Studio API ---
print("🔍 Mengecek koneksi ke Google AI Studio (Gemini)...")
try:
    test_res = requests.post(
        "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions",
        headers={"Authorization": f"Bearer {GOOGLE_API_KEY}", "Content-Type": "application/json"},
        json={"model": "gemini-3.6-flash", "messages": [{"role": "user", "content": "Hi"}], "max_tokens": 10},
        timeout=15
    )
    if test_res.status_code == 200:
        print("✅ Koneksi Google AI Studio berhasil!")
    elif test_res.status_code == 403:
        print("❌ API Key TIDAK VALID atau belum diaktifkan!")
        print("   Dapatkan key baru di https://aistudio.google.com/apikey")
        print(f"   Response: {test_res.text}")
        exit(1)
    elif test_res.status_code == 429:
        print("⚠️ Rate limit! Tunggu 1-2 menit lalu coba lagi.")
        print(f"   Response: {test_res.text}")
        exit(1)
    else:
        print(f"⚠️ Status tidak terduga: {test_res.status_code}")
        print(f"   Response: {test_res.text}")
        exit(1)
except requests.exceptions.Timeout:
    print("❌ Koneksi timeout! Periksa koneksi internet Anda.")
    exit(1)
except Exception as e:
    print(f"❌ Error koneksi: {e}")
    exit(1)

# --- Inisialisasi model ---
model = OpenAIServerModel(
    model_id="gemini-3.6-flash",
    api_base="https://generativelanguage.googleapis.com/v1beta/openai/",
    api_key=GOOGLE_API_KEY
)

# ============================================
# 2. INISIALISASI AGENT DENGAN TOOL SEARCH
# ============================================
tools = [
    DuckDuckGoSearchTool(),
]

agent = ToolCallingAgent(
    tools=tools,
    model=model,
    max_steps=6
)

# ============================================
# 3. JALANKAN PROMPT MULTI-STEP (Search + Kalkulasi)
# ============================================
prompt = """
Cari tahu harga emas 24 karat per gram di Indonesia hari ini (cari di berita atau situs terpercaya).
Setelah dapat harganya, hitung berapa harga untuk membeli 10 gram emas.
"""

print("\n🚀 Menjalankan agent (Search + Kalkulasi)...")
try:
    result = agent.run(prompt)
    print("\n=== JAWABAN AGENT ===")
    print(result)
except Exception as e:
    print(f"\n❌ Agent error: {e}")

Cara Menjalankan Lab 2

  1. Pastikan laptop Anda terhubung dengan koneksi internet aktif.
  2. Pastikan library duckduckgo-search sudah terinstal.
  3. Simpan script di atas dengan nama lab2.py.
  4. Jalankan perintah berikut di terminal:
python lab2.py
DuckDuckGoSearchTool() tidak memerlukan API key tambahan dan bebas kuota berbayar!

Analisis Log Eksekusi Agent

[STEP 1] Agent memutuskan memanggil DuckDuckGoSearchTool:
duckduckgo_search(query='harga emas 24 karat hari ini indonesia per gram')
[OBSERVATION] Web snippet returned:
"...harga emas batangan 24K hari ini berada pada kisaran Rp 1.500.000 per gram..."
[STEP 2] Agent melakukan penalaran kalkulasi:
10 x Rp 1.500.000 = Rp 15.000.000
=== JAWABAN AGENT ===
Untuk membeli 10 gram emas 24 karat hari ini dibutuhkan sekitar Rp 15.000.000.
Hebat! Agent Anda telah berhasil memadukan live internet browsing dengan logika kalkulasi.
