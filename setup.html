Panduan Instalasi Python, Virtual Environment & Library

Panduan komprehensif langkah-demi-langkah untuk menyiapkan mesin lokal Anda sebelum menjalankan rangkaian hands-on Agentic AI (Windows, macOS, dan Linux).

Instalasi Python 3.10+ (Multi-OS)

Pilih sistem operasi laptop yang Anda gunakan

KRUSIAL UNTUK PENGGUNA WINDOWS! Saat jendela installer Python terbuka, Anda WAJIB mencentang kotak:
☑ Add python.exe to PATH (atau "Add Python to PATH")

Jika terlewat, perintah python dan pip tidak akan dikenali di Command Prompt atau PowerShell.

Langkah 1.1

Unduh Installer Resmi

Kunjungi situs resmi Python dan unduh versi terbaru (3.10, 3.11, atau 3.12):

python.org/downloads
Langkah 1.2

Jalankan File .exe

Buka file installer yang diunduh. Centang Add python.exe to PATH di pojok bawah, lalu klik Install Now.

Langkah 1.3

Disable Path Limit (Opsional)

Di akhir instalasi, jika muncul opsi "Disable path length limit", klik opsi tersebut agar path panjang tidak menimbulkan error.

Opsi Rekomendasi: Homebrew

Via Terminal Homebrew

Jika Anda menggunakan Homebrew di macOS, jalankan:

brew install python@3.11
Opsi Installer .pkg

Via Installer Resmi Python.org

Unduh installer universal package macOS:

Unduh macOS 64-bit universal installer

Instalasi di Ubuntu / Debian

Jalankan perintah apt berikut (termasuk modul venv dan dependensi grafis PyAutoGUI):

sudo apt update && sudo apt install -y python3 python3-pip python3-venv python3-tk scrot

3

Membuat & Mengaktifkan Virtual Environment (venv)

Mengisolasi package library agar tidak bentrok dengan sistem OS

Best Practice

Virtual Environment (venv) adalah ruang kerja terisolasi untuk proyek Python Anda. Setiap library yang Anda instal hanya berada di dalam folder proyek ini, menjaga kestabilan sistem komputer Anda.

1. Buat Folder & Venv

Ketikkan di terminal secara berurutan:

# Buat direktori proyek & masuk
mkdir agentai_workshop
cd agentai_workshop

# Buat virtual environment bernama 'agentai_venv'
python -m venv agentai_venv
Sebuah folder agentai_venv/ akan otomatis terbentuk.

2. Aktifkan Venv

Pilih perintah sesuai shell terminal Anda:

# OPSI 1: Windows PowerShell
.\agentai_venv\Scripts\Activate.ps1

# OPSI 2: Windows Command Prompt (CMD)
.\agentai_venv\Scripts\activate.bat

# OPSI 3: macOS / Linux (bash/zsh)
source agentai_venv/bin/activate
Tanda venv berhasil aktif: Muncul teks (agentai_venv) di depan baris prompt terminal!
Mengatasi Error PowerShell: "cannot be loaded because running scripts is disabled"

Secara default, Windows PowerShell membatasi eksekusi file script (.ps1). Jika saat aktivasi muncul pesan merah ExecutionPolicy, jalankan perintah berikut di PowerShell Anda:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Perintah di atas hanya berlaku aman untuk sesi terminal yang sedang terbuka dan tidak mengubah konfigurasi keamanan global sistem Anda.

4

Instalasi Pustaka & Dependensi AI

Menginstal Smolagents, Flask, PyAutoGUI, dan utility penunjang

Pastikan virtual environment telah aktif ((agentai_venv)), kemudian jalankan:

# Perintah Instalasi Satu Baris (Terminal) 
# 1. Upgrade pip ke versi paling baru
python -m pip install --upgrade pip

# 2. Install seluruh paket workshop sekaligus
pip install smolagents flask flask-cors pyautogui pyperclip requests python-dotenv duckduckgo-search openai
Atau jika Anda memiliki file requirements.txt di folder: jalankan pip install -r requirements.txt

Detail Fungsi Setiap Library di Workshop

Nama Library Kategori Fungsi dalam Lab
smolagents Framework AI Framework agen cerdas ringan dari Hugging Face yang menggerakkan siklus ReAct (Reason + Action) dan Tool Calling.
flask & flask-cors Web Server Menyediakan REST API endpoint (/chat) untuk menghubungkan antarmuka frontend HTML dengan backend agent Python.
pyautogui Desktop RPA Mengendalikan mouse dan pengetikan keyboard otomatis ke aplikasi desktop Microsoft Word secara otonom.
pyperclip Clipboard Tool Menjamin teks bahasa Indonesia, karakter aksara, dan emoji tidak hilang saat ditempelkan (paste) ke Microsoft Word.
duckduckgo-search Live Search Memungkinkan agent berselancar ke internet untuk mengambil fakta dan berita terkini secara real-time tanpa perlu API key berbayar.
python-dotenv Keamanan Membaca kredensial API Key dari berkas rahasia .env sehingga kunci tidak ter-hardcode di script Python.
5

Mendapatkan & Mengonfigurasi API Key Google AI Studio (.env)

Kredensial gratis untuk mengakses model Gemini 3.6 Flash

  1. Buka browser Anda dan kunjungi portal resmi Google AI Studio: aistudio.google.com/apikey
  2. Masuk (Sign in) menggunakan akun Google pribadi Anda.
  3. Klik tombol biru "Create API key".
  4. Pilih proyek Google Cloud baru atau yang sudah ada, lalu klik "Create key in new project".
  5. Salin string API key yang muncul (diawali dengan AIzaSy...).
  6. Buat file bernama persis .env di dalam folder proyek Anda.
Peringatan Privasi: Jangan pernah membagikan atau mengunggah berkas .env ke repository publik GitHub!
.env 
# Konfigurasi Kunci API Google AI Studio (Gemini)
# Dapatkan gratis di: https://aistudio.google.com/apikey
GOOGLE_API_KEY=AIzaSy_GANTI_DENGAN_KEY_ANDA_DISINI

Ganti teks AIzaSy_GANTI_DENGAN_KEY_ANDA_DISINI dengan API Key yang Anda salin dari Google AI Studio.

6

Uji Validasi Lingkungan (Smoke Test)

Memastikan semua library terpasang dan API Key terbaca sempurna

Buat file pengujian sederhana bernama test_env.py di folder proyek Anda untuk memeriksa kesiapan sistem:

test_env.py 
import os
from dotenv import load_dotenv

load_dotenv()
key = os.getenv("GOOGLE_API_KEY")

print("🔍 Memeriksa dependensi...")
try:
    import smolagents
    import flask
    import pyautogui
    import pyperclip
    import requests
    print("✅ Semua library berhasil di-import!")
except ImportError as e:
    print(f"❌ Ada library yang kurang: {e}")

if key and not key.startswith("AIzaSy_GANTI"):
    print(f"✅ GOOGLE_API_KEY ditemukan: {key[:8]}... (Valid)")
else:
    print("⚠️ GOOGLE_API_KEY belum diset dengan benar di file .env")

Jalankan di terminal:

python test_env.py

Output yang diharapkan:

🔍 Memeriksa dependensi...
✅ Semua library berhasil di-import!
✅ GOOGLE_API_KEY ditemukan: AIzaSyD... (Valid)

Selamat! Lingkungan workshop Anda sudah siap 100%. Anda kini siap melangkah ke Lab 1.
